# Capturas directas del navegador

`browser-real/01-login.jpg` a `05-terminal.jpg` se guardaron directamente con la herramienta del navegador durante el acceso real de alumno-demo a Guacamole y su escritorio XFCE. `06-grafana.jpg` captura el dashboard tras actualizar los datos.

`acceso-real.gif` reproduce las cinco capturas de Guacamole en orden, sin superponer títulos, marcos, flechas ni modificar el contenido. La conversión a GIF adapta la paleta de colores; las capturas originales están disponibles. No es vídeo continuo.

`escritorio-rdp.jpg` y `grafana.jpg` son copias de las capturas actuales para enlaces de evidencia. `login.jpg` conserva la captura anterior del mismo formulario.

`demo.cast` contiene la salida real de las pruebas de terminal, en formato asciicast v2.

No contienen contraseñas visibles ni datos de alumnos reales.

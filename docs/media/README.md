# Medios de la prueba

- `demo.cast`: asciicast v2 producido por comandos ejecutados el 2026-11-03; `asciinema play demo.cast` reproduce la salida completa.
- `demo.gif`: resumen visual derivado de esa captura, con ajuste de líneas al tamaño del fotograma. Consultar el cast para salidas extensas.
- `login.png`: formulario inicial real de Guacamole.
- `escritorio-rdp.png`: XFCE real abierto por RDP desde Guacamole; terminal con `whoami` y resultado `alumno`.
- `grafana.png`: dashboard real con indicador 1 y gráfica de latencia.

No contienen contraseñas ni datos de alumnos reales. Los identificadores de contenedor y horarios corresponden al entorno efímero de la prueba. La animación de terminal no se presenta como vídeo del escritorio.
